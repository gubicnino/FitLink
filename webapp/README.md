# FitLink Web App

Admin and trainer dashboard for the FitLink platform — built with React + TypeScript.

---

## Stack

- **React** + **TypeScript**
- **Firebase Auth** (email/password, Google)

---

## Prerequisites

- **Node.js 22 LTS** + **npm 10+**

---

## Getting Started

### 1. Install dependencies

```bash
cd webapp
npm install
```


> Use the same Firebase project as the mobile app.

### 2. Start dev server

```bash
npm run dev
```

App will be available at `http://localhost:5173`.

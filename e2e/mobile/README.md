# e2e/mobile

Rezervirano za funkcionalne teste mobilne aplikacije (`mobile-app/`) z Appiumom.

Načrt: isti zaganjalnik kot `e2e/web/` (WebdriverIO), dodata se `@wdio/appium-service` in lastna
`wdio.conf.ts` z Android/iOS capabilities. Seed skripta in testni računi so skupni.

Trenutno tukaj ni testov.
